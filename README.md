# Matrix Number Guessing Game

This project is an interactive, retro-futuristic (Cyberpunk/Matrix) themed number guessing game developed using modern web technologies. The goal is to find the hidden number generated by the computer in the fewest moves and the shortest time possible, based on the selected difficulty level.

## Key Features

* **Dynamic Matrix Background:** A continuous falling digital rain effect created with HTML5 Canvas and JavaScript.
* **Difficulty Levels:**
    * **Easy:** Guess a number between 1-50.
    * **Medium:** Guess a number between 1-100.
    * **Hard:** Guess a number between 1-200.
* **Smart Hint System:** Provides mathematical clues, such as whether the number is prime, to assist the player.
* **Interactive Number Grid:** A dynamic table where you can visually track your guessed numbers.
* **Performance Tracking:** Includes a stopwatch to track elapsed time and a counter for the number of attempts.
* **Visual Celebration:** Uses the `canvas-confetti` library to trigger a celebration effect upon a correct guess.

## 🛠️ Technologies Used

* **HTML5:** Game structure and content management.
* **CSS3:** Matrix-themed custom animations, neon effects, and responsive design.
* **JavaScript (ES6+):** Game logic, mathematical checks, DOM manipulation, and the Matrix effect.
* **Canvas API:** Utilized for the background digital rain animation.

## File Structure

- `index.html`: The main skeleton of the game.
- `style.css`: Visual design and neon styling.
- `script.js`: Game engine and core functionalities.

## Getting Started

No server setup is required to run this project on your local machine.

1.  Clone this repository:
    ```bash
    git clone [https://github.com/yourusername/matrix-guessing-game.git](https://github.com/yourusername/matrix-guessing-game.git)
    ```
2.  Navigate to the project directory.
3.  Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox, etc.).

## How to Play

1.  Select a difficulty level using the buttons at the top.
2.  Enter a number in the guess box or click on a number from the grid below.
3.  Click the **"Guess"** button.
4.  Follow the directions (**Higher/Lower**) provided in the hints section.
5.  Once you find the correct number, enjoy the confetti celebration!

# Matrix Sayı Tahmin Oyunu

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş, retro-gelecekçi (Cyberpunk/Matrix) temalı interaktif bir sayı tahmin oyunudur. Kullanıcının seçtiği zorluk seviyesine göre bilgisayarın tuttuğu gizli sayıyı en az hamlede ve en kısa sürede bulması hedeflenir.

## Öne Çıkan Özellikler

* **Dinamik Matrix Arkaplanı:** HTML5 Canvas ve JavaScript ile oluşturulmuş sürekli akan sayı yağmuru efekti.
* **Zorluk Seviyeleri:**
    * **Kolay:** 1-50 arası sayı tahmini.
    * **Orta:** 1-100 arası sayı tahmini.
    * **Zor:** 1-200 arası sayı tahmini.
* **Akıllı İpucu Sistemi:** Sayının asal olup olmadığı gibi matematiksel ipuçları ile oyuncuya yardımcı olur.
* **İnteraktif Sayı Izgarası:** Tahmin edilen sayıları görsel olarak takip edebileceğiniz dinamik bir tablo.
* **Performans Takibi:** Geçen süreyi tutan bir kronometre ve hamle sayısı sayacı.
* **Görsel Şölen:** Doğru tahmin durumunda `canvas-confetti` kütüphanesi ile kutlama efekti.

## 🛠️ Kullanılan Teknolojiler

* **HTML5:** Oyun yapısı ve içerik yönetimi.
* **CSS3:** Matrix temalı özel animasyonlar, neon efektleri ve duyarlı (responsive) tasarım.
* **JavaScript (ES6+):** Oyun mantığı, matematiksel kontroller, DOM manipülasyonu ve Matrix efekti.
* **Canvas API:** Arkaplan animasyonu için kullanıldı.

## Dosya Yapısı

- `index.html`: Oyunun ana iskeleti.
- `style.css`: Görsel tasarım ve neon efektleri.
- `script.js`: Oyun motoru ve tüm fonksiyonlar.

## Başlangıç

Projeyi yerel makinenizde çalıştırmak için herhangi bir sunucu kurulumuna gerek yoktur. 

1.  Bu depoyu klonlayın:
    ```bash
    git clone [https://github.com/kullaniciadi/sayi-tahmin-oyunu.git](https://github.com/kullaniciadi/sayi-tahmin-oyunu.git)
    ```
2.  Proje klasörüne gidin.
3.  `index.html` dosyasını herhangi bir modern web tarayıcısı (Chrome, Edge, Firefox vb.) ile açın.

## Nasıl Oynanır?

1.  Üst kısımdaki butonlardan bir zorluk seviyesi seçin.
2.  Tahmin kutusuna bir sayı girin veya aşağıdaki sayı ızgarasından bir sayıya tıklayın.
3.  "Tahmin Et" butonuna basın.
4.  İpucu kısmındaki yönlendirmeleri (Daha Büyük/Daha Küçük) takip edin.
5.  Sayıyı bulduğunuzda konfeti kutlamasıyla karşılaşacaksınız!
