# Matrix Sayı Tahmin Oyunu

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş, retro-gelecekçi (Cyberpunk/Matrix) temalı interaktif bir sayı tahmin oyunudur. Kullanıcının seçtiği zorluk seviyesine göre bilgisayarın tuttuğu gizli sayıyı en az hamlede ve en kısa sürede bulması hedeflenir.

## Öne Çıkan Özellikler

* **Dinamik Matrix Arkaplanı:** HTML5 Canvas ve JavaScript ile oluşturulmuş sürekli akan sayı yağmuru efekti.
* **Zorluk Seviyeleri:** * **Kolay:** 1-50 arası sayı tahmini.
    * **Orta:** 1-100 arası sayı tahmini.
    * **Zor:** 1-200 arası sayı tahmini.
* **Akıllı İpucu Sistemi:** Sayının asal olup olmadığı gibi matematiksel ipuçları ile oyuncuya yardımcı olur.
* **İnteraktif Sayı Izgarası:** Tahmin edilen sayıları görsel olarak takip edebileceğiniz dinamik bir tablo.
* **Performans Takibi:** Geçen süreyi tutan bir kronometre ve hamle sayısı sayacı.
* **Görsel Şölen:** Doğru tahmin durumunda `canvas-confetti` kütüphanesi ile kutlama efekti.

## 🛠️ Kullanılan Teknolojiler

* **HTML5:** Oyun yapısı ve içerik yönetimi.
* **CSS3:** Matrix temalı özel animasyonlar, neon efektleri ve duyarlı (responsive) tasarım.
* **JavaScript (ES6+):** Oyun mantığı, matematiksel kontroller, DOM manipülasyonu ve Matrix efekti.
* **Canvas API:** Arkaplan animasyonu için kullanıldı.

## Dosya Yapısı

- `index.html`: Oyunun ana iskeleti.
- `style.css`: Görsel tasarım ve neon efektleri.
- `script.js`: Oyun motoru ve tüm fonksiyonlar.

## Başlangıç

Projeyi yerel makinenizde çalıştırmak için herhangi bir sunucu kurulumuna gerek yoktur. 

1.  Bu depoyu klonlayın:
    ```bash
    git clone [https://github.com/kullaniciadi/sayi-tahmin-oyunu.git](https://github.com/kullaniciadi/sayi-tahmin-oyunu.git)
    ```
2.  Proje klasörüne gidin.
3.  `index.html` dosyasını herhangi bir modern web tarayıcısı (Chrome, Edge, Firefox vb.) ile açın.

## Nasıl Oynanır?

1.  Üst kısımdaki butonlardan bir zorluk seviyesi seçin.
2.  Tahmin kutusuna bir sayı girin veya aşağıdaki sayı ızgarasından bir sayıya tıklayın.
3.  "Tahmin Et" butonuna basın.
4.  İpucu kısmındaki yönlendirmeleri (Daha Büyük/Daha Küçük) takip edin.
5.  Sayıyı bulduğunuzda konfeti kutlamasıyla karşılaşacaksınız!
